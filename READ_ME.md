1. При запуске убедитесь что создали файл .env
такого содержания:

API_KEY="xxxxxxxxxxxxxxxxxxxxxxxxxx"
WEATHER_API_KEY="xxxxxxxxxxxxxxxxxxxxxxxxx"

2. Также для работы виджета для мониторинга "температуры процессора" 
нужно открыть среду разработки с правами администратора, без них программа запустится,
но виджет покажет ошибку внутри консоли программы. Возможно у вас найдется другое решение :)

3. Логин и пароль: admin admin
Изначально программа не предусматривала регистрацию, можете либо прикрутить свое окно
лиюо записывать сразу в базу данных (users.db)

4. Два файла config.json и config.csv
Желательно чтобы в config.json вы указали свой base_dir и прочее, это навсякий случай,
чтобы исключить большое количество сбоев. Также удобно если вы будете разбирать проект
или же наоборот структурировать.

5. requirements.txt - там лежат все зависимости, надеюсь... (pip install -r requirements)

6. user_data.pcl - нужен для remember me в окне авторизации, но он запоминает данные и без нажатия 
данной кнопки) Запоминает на 8 часов с моменто входа, после удаляет файл

7. Включение через main.py

8. Пройдемся по папкам: 

- admin_logs - логи, которые можно получить через админ панель (создание криптоключа(флешки) 
описано ниже либо можете взять готовые данные)

- backups - нужна для голосового ассистента для того чтобы вы могли сделать резервную копию файла

- images - иконки, картинки

- model - модели для синтеза речи

- results - нужна для голосового ассистента для работы с нейроредактором кода

- sounds - системные звуки

- ui_components - это все для работы с QT_designer

- unique_csv - набор csv файлов для графиков и тд 

- voice_assistant - все от голосового ассистента функции, команды, звуки

- widgets - большинство виджетов из программы. да-да есть те которые просто лежат в main.py, 
но как говорил ранее если будет интерес к проекту то все структурирую
